How the predictor works

This prototype uses transparent calculations so you can explain it in a college project demonstration.

1. Estimated days left

Current stock ÷ average daily sales. If daily sales are zero, the estimate is shown as unavailable.

2. Reorder point

(Average daily sales × supplier lead time) + safety stock.

3. Risk detection

If stock is at or below the reorder point, the item is flagged for reordering. If estimated days left is less than supplier lead time, it is marked as stockout risk.

4. Suggested order

Suggests enough units to cover lead-time demand plus safety stock, minus current stock. Check supplier pack sizes and business needs before ordering.

Important: this version is an educational prototype, not a trained machine-learning model. It does not use live sales data or a cloud AI service. Forecast accuracy depends on the numbers entered. Data is saved in this browser only.
